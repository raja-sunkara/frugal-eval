# Changelog

## 0.3.0

- New "find the best" methods: Track-and-Stop (Garivier & Kaufmann, COLT 2016) and EB-TC (Jourdan, Degenne & Kaufmann, NeurIPS 2023)
- Benchmark figure in the README (light and dark), generated by `benchmarks/plot.py`
- `benchmarks/run_all.py` now also writes `benchmarks/summary.json` and the figure
- More robust tests across Python 3.9 to 3.13; CI reports every Python version

## 0.2.0

- Plugin interface: methods and tasks registries with paper metadata
- 19 methods across three problems: find the best, estimate scores, online selection and routing
- Real Open LLM Leaderboard data shipped with the package; `frugal-eval demo`; Colab notebook
- BENCHMARKS.md comparing every method on the same data

## 0.1.0

- Adaptive best-candidate search (LUCB) with finite-population confidence bounds and paired comparisons
