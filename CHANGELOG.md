# Changelog

## 0.5.0

- New problem, pairwise comparisons (`find_best_pairwise`, `frugal-eval duel`): round robin, Borda reduction with
  LUCB and with successive elimination (Jamieson et al., AISTATS 2015), SAVAGE (Urvoy et al., ICML 2013)
- Chatbot Arena human vote counts bundled (lmarena-ai/arena-human-preference-55k, Apache-2.0): 59 models, 56k votes
- Drift scenario (`drift/<benchmark>`): the best model silently degrades mid-stream; non-stationary methods
  Discounted UCB and Sliding-Window UCB (Garivier & Moulines, ALT 2011) and Discounted Thompson Sampling
  (Raj & Kalyani, 2017)
- One command per job: `frugal-eval identify | estimate | route | duel`
- README method zoo, updated automatically by the benchmark workflow; CITATION.cff; issue and PR templates
- Fixed the RouterBench benchmark job (data was prepared separately in every worker process)

## 0.4.0

- Cost-aware online selection: `run_online(..., cost_weight=)` trades quality against dollar cost
- RouterBench task (Hu et al., 2024): 11 LLMs on 36k real prompts with real costs, downloaded from
  Hugging Face on first use (`pip install "frugal-eval[routerbench]"`), with prompt embeddings
- Benchmark workflow on GitHub: one parallel job per task, now including MMLU and HellaSwag, plus RouterBench
- Data workflow that downloads external datasets in GitHub Actions for review

## 0.3.0

- New "find the best" methods: Track-and-Stop (Garivier & Kaufmann, COLT 2016) and EB-TC (Jourdan, Degenne & Kaufmann, NeurIPS 2023)
- Benchmark figure in the README (light and dark), generated by `benchmarks/plot.py`
- `benchmarks/run_all.py` now also writes `benchmarks/summary.json` and the figure
- More robust tests across Python 3.9 to 3.13; CI reports every Python version

## 0.2.0

- Plugin interface: methods and tasks registries with paper metadata
- 19 methods across three problems: find the best, estimate scores, online selection and routing
- Real Open LLM Leaderboard data shipped with the package; `frugal-eval demo`; Colab notebook
- BENCHMARKS.md comparing every method on the same data

## 0.1.0

- Adaptive best-candidate search (LUCB) with finite-population confidence bounds and paired comparisons
